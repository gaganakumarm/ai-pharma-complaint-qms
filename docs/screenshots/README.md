# Screenshot Capture Checklist

Use only fictional sample data. Before capture, close developer tools and confirm no API key, `.env` content, personal information, absolute path, or debug output is visible.

1. `01-main-workspace.png` — clean main complaint intake workspace.
2. `02-fdf-populated-form.png` — fictional FDF PDF extraction with editable fields.
3. `03-quality-risk-panel.png` — category, severity, risk, next action, and disclaimer.
4. `04-conversational-correction.png` — corrected fictional batch and quantity.
5. `05-completeness-panel.png` — percentage and required/recommended gaps.
6. `06-duplicate-panel.png` — ranked possible match and QA-review wording.
7. `07-rca-capa-panel.png` — hypotheses, evidence, actions, and trusted disclaimer.
8. `08-committed-complaint.png` — successful fictional complaint number/status.
9. `09-api-docs.png` — optional Swagger endpoint overview without request secrets.
10. `10-passing-tests.png` — optional terminal showing final totals and no sensitive paths where practical.

Capture the browser at a readable desktop width. Crop to the application or relevant terminal region; do not fabricate or add empty image placeholders.
